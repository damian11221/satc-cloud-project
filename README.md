# SATC Cloud Project

This repository contains practical AWS implementation files for the Savanna Artisan Trading Cooperative (SATC) cloud migration project.

## Included files
- `index.html` - SATC web page
- `lambda_function.py` - Lambda function for reading products from DynamoDB
- `buildspec.yml` - AWS CodeBuild configuration
- `appspec.yml` - AWS CodeDeploy configuration
- `SATC-Infrastructure.yaml` - CloudFormation template
- `scripts/restart_httpd.sh` - Deployment script for Apache
